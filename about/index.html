Security & Architecture

About Drop

Drop is a lightweight, zero-knowledge, end-to-end encrypted file sharing web application. All encryption happens locally inside your browser before uploading — we never see or store your unencrypted files.

Zero-Knowledge Security

End-to-end encryption designed for maximum privacy.

Client-Side AES-GCM

Files are encrypted in your browser using AES-GCM-256 with random IVs before being transmitted.

Zero-Knowledge Short Links

Decryption keys are placed in URL hash fragments (#token). Browsers never send fragments to servers, keeping keys private.

Automatic Server Cleanup

Encrypted files automatically expire in 30 minutes and server copies are destroyed immediately after a successful download.

Technical Implementation

Modern Web APIs and performance-first engineering.

Web Crypto & Streaming

Leveraging native SubtleCrypto and TransformStream for low-latency, memory-efficient streaming encryption.

Resumable Transfer Manager

Supports multi-file streaming, progress tracking, and robust error recovery without consuming incomplete server copies.

Solid Glass UI

Crafted with modern CSS glassmorphism, dynamic SVG refraction shaders, and responsive squircle geometry.
